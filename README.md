# Personal Expense Tracker

A simple personal expense tracker built with HTML, CSS, and JavaScript.

## Features
- Add monthly expenses with name, amount, category, and month.
- Delete individual expenses.
- Clear all expenses.
- Automatically calculates total expenses.
- Highlights big expenses (> ₹10,000).
- Gives suggestion if total expenses exceed ₹45,000.

## How to Use
1. Open `index.html` in a browser.
2. Click "Start" to go to the tracker page.
3. Add your expenses using the form.
4. View, delete, or clear all expenses.
5. Total expenses and suggestions are automatically updated.
